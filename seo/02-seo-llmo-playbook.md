# 手順6：SEO と LLMO で「必要な人に見つけてもらう」実務手順

技術的な設定（手順1〜5）は土台です。**順位を決めるのはコンテンツ側**です。
ここでは「何を、どう書くか」を具体的に定めます。

---

## 前提：SEOとLLMOは評価軸が違う

| | SEO（Google検索） | LLMO（ChatGPT・Claude・AI Overviews） |
|---|---|---|
| 拾われる単位 | **ページ** | **文・段落** |
| 効くもの | 被リンク・網羅性・滞在時間 | **断定的な一文・数値・定義・Q&A** |
| 順位の見え方 | 1位〜10位 | 引用されるか／されないか（0か1） |
| 致命傷 | 重複コンテンツ | **曖昧な表現**（AIは引用できない） |

**両立のコツ**：記事の冒頭に「AIが切り取れる断定文」を置き、
その後にSEO向けの詳細解説を続ける。この順番が最も効率的です。

---

## 1. ページ設計：1ページ＝1検索意図

1ページに複数のテーマを詰めると、Googleは「何のページか」を判定できません。

```
❌ 「サービス紹介・料金・お客様の声・会社概要」を1ページに
✅ /service/      … 何ができるか
   /service/price/… いくらか
   /case/         … 実績
   /company/      … 誰がやっているか
```

**作るべきページの優先順位**

| 優先 | ページ | 理由 |
|---|---|---|
| 1 | サービス個別ページ（1サービス1ページ） | 購入意欲の高い検索を受ける |
| 2 | 料金・費用ページ | 「〇〇 費用」は最も成約に近い検索 |
| 3 | 導入事例（数値入り） | E-E-A-T と AI引用の両方に効く |
| 4 | FAQ | LLMOで最も引用されやすい形式 |
| 5 | 用語解説・「〇〇とは」記事 | AIの定義質問に対する回答源になる |
| 6 | 代表・執筆者プロフィール | 誰が言っているかが評価される |

---

## 2. タイトルタグの型

```
【主要キーワード】＋【差別化要素】｜【会社名】
```

- **全角30文字前後**（超えると検索結果で切れる）
- キーワードは**必ず左寄せ**
- 差別化要素には**数字**を入れる

```
❌ サービスのご案内｜株式会社サンプル
✅ 中小企業向けマーケティング講座｜受講1,200社・実践型｜株式会社サンプル
```

---

## 3. 見出し構造（AIが最も参照する部分）

```
H1  … ページに1つだけ。タイトルとほぼ同義
 H2 … 検索意図の分解単位。ここに関連キーワードを入れる
  H3 … H2の詳細
```

**H2は「疑問文」または「名詞句」にする**。AIは見出しを目次として読み、
質問と一致した見出しの下の文章を引用します。

```
❌ H2: 当社の強み
✅ H2: マーケティング講座の費用相場はいくらか
✅ H2: 未経験から始める場合に必要な期間
```

---

## 4. LLMOで引用される文章の書き方

生成AIは**「そのままコピーして回答に貼れる文」**を探しています。

### 4-1. 各H2の直下に「答えの一文」を置く

```markdown
## マーケティング講座の費用相場はいくらか

中小企業向けマーケティング講座の費用相場は、3ヶ月コースで
30万円〜80万円である。当社の基本プランは月額◯◯円（税込）で、
初期費用はかからない。

（↑ここまでがAIに引用される。以降は人間向けの詳細解説）
```

### 4-2. 使ってはいけない表現 / 使うべき表現

| ❌ AIが引用できない | ✅ AIが引用できる |
|---|---|
| 業界最高水準のサポート | 平均返信時間は営業時間内4時間以内 |
| 多くのお客様にご満足いただいています | 受講後アンケートの満足度は94.2%（2025年度・回答者318名） |
| 豊富な実績 | 1990年の創業以来、1,200社を支援 |
| リーズナブルな価格 | 月額◯◯円（税込）、初期費用0円 |
| 弊社独自のメソッド | ◯◯式3ステップ法（①調査 ②設計 ③検証） |

**鉄則：形容詞を数字に置き換える。** これだけで引用率が変わります。

### 4-3. 必ず入れる4要素

1. **定義文** … 「〇〇とは、〜である。」の形を1記事に最低1つ
2. **数値** … 年・件数・％・金額。出典と時点を添える
3. **Q&A** … ページ下部にFAQを3〜5問（`functions-seo.php` の設定に同じ内容を登録）
4. **更新日の明示** … AIも検索も「いつの情報か」を重視します

---

## 5. E-E-A-T（誰が言っているか）

Googleは2022年以降、**経験（Experience）** を評価軸に加えています。
AIも同様に「一次情報を持つ発信者」を優先して引用します。

- [ ] 全記事に**著者名と役職**を表示する（`functions-seo.php` が構造化データ側を出力）
- [ ] 著者プロフィールページに **経歴・実績・保有資格・著書・登壇歴** を書く
- [ ] 会社概要に **設立年・所在地・代表者名・資本金** を明記
- [ ] 実体験（自社で試した結果・失敗談・具体的な数値）を本文に入れる
- [ ] 外部メディア掲載・受賞歴があれば `same_as` に URL を追加

## 6. 表示速度（Core Web Vitals）

Search Console の **［エクスペリエンス］→［ウェブに関する主な指標］** で確認。

| 指標 | 目標 | よくある原因と対処 |
|---|---|---|
| LCP（表示速度） | 2.5秒以下 | メイン画像を WebP 化・`loading="lazy"` を最初の1枚には付けない |
| INP（反応速度） | 200ms以下 | 不要なプラグインを削除、JSの遅延読み込み |
| CLS（レイアウト崩れ） | 0.1以下 | 画像に `width` `height` を必ず指定 |

WordPress での即効策：
1. 使っていないプラグインを**停止ではなく削除**
2. 画像最適化プラグイン（EWWW・Converter for Media 等）で WebP 変換
3. キャッシュプラグインを**1つだけ**導入（複数入れると競合します）

## 7. 効果測定（月1回・15分）

| 見る場所 | 見る数字 | 判断 |
|---|---|---|
| Search Console →［検索結果］ | 表示回数・クリック数・掲載順位 | 表示回数↑・順位↓ = キーワードが広すぎる |
| Search Console →［ページ］ | インデックス登録済み件数 | 公開ページ数と大きく乖離していないか |
| ChatGPT / Claude / Perplexity | 「【自社の商圏】＋【サービス名】でおすすめは？」と質問 | **自社名が出るか**。これがLLMOの唯一の指標 |

LLMOには順位表がありません。**実際にAIに質問して確認する**のが唯一の方法です。
月1回、同じ質問を投げてスクリーンショットを保存しておくと変化が追えます。

---

## 8. 90日ロードマップ

| 期間 | やること |
|---|---|
| **1〜2週目** | 手順1〜3を実施（リダイレクト診断・URL正規化・robots.txt）。Search Console で再検証を開始 |
| **3〜4週目** | 手順4〜5（構造化データ・llms.txt）。[リッチリザルトテスト](https://search.google.com/test/rich-results) でエラーが出ないことを確認 |
| **2ヶ月目** | 優先ページ（サービス・料金・事例・FAQ）を上記2〜4の型で書き直す。形容詞を数字に置換 |
| **3ヶ月目** | 「〇〇とは」記事を月4本追加。各記事の冒頭に定義文を配置。AIに質問して引用状況を確認 |

---

## 実装後の必須チェック

- [ ] [リッチリザルトテスト](https://search.google.com/test/rich-results) で構造化データにエラー・警告がない
- [ ] `https://example.co.jp/robots.txt` がブラウザで開ける
- [ ] `https://example.co.jp/llms.txt` がブラウザで開ける
- [ ] `https://example.co.jp/sitemap.xml` に転送されるURLが載っていない
- [ ] 主要ページのソースを表示し、`<link rel="canonical">` が**1つだけ**で、最終URLを指している
- [ ] トップページが**転送0回**で表示される
