# ============================================================
# 【補足】AIクローラを許可するかの判断
# ------------------------------------------------------------
# 許可する  → ChatGPT・Claude・Perplexity・AI Overviews に
#             自社情報が引用される可能性が上がる（＝LLMO）
# 拒否する  → 学習データに使われないが、AI経由の流入もゼロになる
#
# 「必要な人に見つけてもらう」ことが目的であれば、許可が正解です。
