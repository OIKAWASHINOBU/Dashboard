# 手順0：現状データの集め方（コピペで完結）

このセッションからは外部サイトへの通信が遮断されているため、
`https://o-snb.com` を直接見に行くことができません。

代わりに、**下の5つをブラウザからコピーして貼っていただければ**、
実物ベースで「どこが原因か」「どこを直すか」を specific に診断できます。
すべてブラウザだけで完結します。所要 約10分。

---

## ① トップページのHTMLソース ★最優先★

**これ1つで、canonical・見出し構造・構造化データ・使用プラグインまで全部わかります。**

1. `https://o-snb.com` をブラウザで開く
2. ページの何もない所で **右クリック → 「ページのソースを表示」**
   （Mac: `⌘ + Option + U` ／ Windows: `Ctrl + U`）
3. 開いたページで **全選択**（`⌘ + A` / `Ctrl + A`）→ **コピー**（`⌘ + C` / `Ctrl + C`）
4. チャットに貼り付け

> 長くて貼りきれない場合は、**`</head>` と書かれている行までで構いません**。
> 診断に必要な情報の9割は `<head>` の中にあります。

---

## ② robots.txt

ブラウザで開いて、表示された文字を全部コピー：

```
https://o-snb.com/robots.txt
```

- **404 になる場合** → 「404でした」とだけ教えてください（それも重要な情報です）

---

## ③ サイトマップ

次の順に試して、**開けたURL**と**中身**を教えてください：

```
https://o-snb.com/sitemap.xml
https://o-snb.com/sitemap_index.xml     ← Yoast SEO の場合
https://o-snb.com/wp-sitemap.xml        ← WordPress標準の場合
```

中身が長い場合は、**最初の20行程度**で十分です。
（どのプラグインが動いているかの判別と、旧URL混入のチェックに使います）

---

## ④ Search Console の該当URL一覧 ★今回の警告の本体★

1. Search Console を開く
2. **［インデックス作成］→［ページ］**
3. 下の表から **「ページにリダイレクトがあります」** をクリック
4. 右上の **［エクスポート］→［Google スプレッドシート］** または **［CSV をダウンロード］**
5. **URLの一覧をコピーしてチャットに貼る**（件数が多ければ先頭30件で可）

この一覧があれば、`01-redirect-diagnosis.md` の判定表に沿って
**「放置OK」と「要修正」に私が仕分け**します。

---

## ⑤ 有効化中のプラグイン一覧

1. WordPress管理画面 → **［プラグイン］→［インストール済みプラグイン］**
2. 上部の **「有効」** タブをクリック
3. 表示されているプラグイン名を、**名前だけ箇条書きで**教えてください

例：
```
- Yoast SEO
- Really Simple SSL
- Contact Form 7
- WP Rocket
```

> ここが二重リダイレクトの犯人になっていることが非常に多いです。
> 特に **SSL化プラグイン ×2**、**キャッシュプラグイン ×2**、
> **SEOプラグイン ×2** の同時稼働は要注意です。

---

## おまけ：転送回数を自分で測る

`redirect checker` で検索して出てくる無料ツールに
`https://o-snb.com` を入れると、転送が何段あるか即座にわかります。

| 結果 | 判定 |
|---|---|
| `200` が1回で返る | ✅ 理想 |
| `301 → 200`（1段） | ⭕️ 許容 |
| `301 → 301 → 200`（2段以上） | ❌ 要修正（チェーン） |
| `ERR_TOO_MANY_REDIRECTS` | ❌ 至急修正（循環） |

---

## 補足：私が直接サイトを見られるようにする方法

Claude Code の**環境設定でネットワークポリシーを変更**すると、
次回以降のセッションで私が `o-snb.com` を直接クロールして診断できます。

設定場所：claude.ai/code の環境設定 → ネットワークアクセス
（詳細：https://code.claude.com/docs/en/claude-code-on-the-web ）

ただし上の①〜⑤を貼っていただく方が早いので、まずはそちらを推奨します。
